# Getting Started

## Fastest Path With An AI Coding Tool

1. Open this repo folder in Codex, Claude Code, Cursor, or a similar AI coding tool.
2. Say:

```txt
Set up this job-search Memex for me using my resume and job-search docs.
```

3. Provide your resume as pasted text or a `.txt` / `.md` file.
4. Add optional job-search artifacts if you have them.
5. Open `01 Start Here/Start Here.md` in Obsidian when setup finishes.

## Fastest Local Command

```bash
npm start
```

This starts the same onboarding wizard.

## Manual Path

If you do not want to run the wizard, copy the files in `System/Templates/` into the matching folders and fill them in by hand.

Start in this order:

1. `06 Synthesis/Career/Canonical Resume.md`
2. `06 Synthesis/Career/Resume Evidence Bank.md`
3. `06 Synthesis/Career/Candidate-Market Fit.md`
4. `06 Synthesis/Career/Job Search Strategy.md`
5. `02 Projects/Job Search.md`
6. First weekly review note in `01 Reviews/Weekly/`

## First Week Checklist

- Review the generated canonical resume note.
- Fix anything in Claims To Verify.
- Add one target role or company.
- Capture one conversation or outreach plan.
- Run the first weekly review.
